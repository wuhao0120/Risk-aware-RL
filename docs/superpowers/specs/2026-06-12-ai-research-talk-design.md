# 《AI 智能体与科研工作流》报告与幻灯片 · 设计文档

日期：2026-06-12　|　报告日期：2026-06-15 下午　|　状态：待用户审阅

## 1. 背景与目标

- **场合**：数学学院学术报告，约 60 分钟 + Q&A，面向数学/统计师生。
- **听众画像**：绝大多数只在网页里和 DeepSeek 等模型对话；读数学论文时连公式都靠手敲提问；对 Agent、Harness、MCP、自动化工作流几乎零认知。
- **目标**：① 讲清 2026 年 AI 发展到了哪一步（Chat → Agent → Harness → Workflow）；② 用一个纯数学案例展示 AI 进入真实研究过程的完整 pipeline；③ 讲清能力边界与学术规范；④ 听众"今天回去就能上手"。
- **输入材料**：`talk/邀请函.md`（五点要求）、`talk/报告摘要.md`、`talk/主讲人简介.md`。
- **邀请函五点的覆盖方式**：第一点→第 1 章；第二点→压缩为第 1 章末尾一页"如果你想研究 AI 本身"；第三点→第 2 章；第四点→第 3、4 章（案例 + demo）；第五点→第 5 章。

## 2. 关键决策一览

| 决策点 | 结论 | 理由/备注 |
|---|---|---|
| 幻灯片形式 | 自包含单文件 HTML（浏览器放映）+ PDF 备份 | 美观上限最高；本身即"AI 能做什么"的活案例；不需要 pptx |
| 整体结构 | 双线并行：上半场概念，下半场实战 | 用户选定（方案 C）；以"每概念页配数学场景迷你例子"抵消枯燥风险 |

| 视觉方向 | B「纸墨」：暖白纸底 + 衬线 + 朱砂红 | 用户在 A/B/C 三方向中点选 B；密度采用"满幅 v3 概念页"基准 |

## 3. 报告结构与页预算（约 40 页 / 60 分钟）

### 开场（3′，3 页）
1. 封面（扉页式：标题 + 摘要框 + 关键词条 + 五章目录条）
2. 冷开场：手敲 LaTeX 问 DeepSeek 的截图——"这是 2026 年大多数人的用法，也是 2023 年的用法"
3. 今日地图（上半场认识 AI / 下半场看 AI 做数学研究）

### 第 1 章 · 发展现状（12′，8 页）
- 三级跳：规模 → 多模态 → 推理（每级一个数学相关的能力例证）
- 模型版图矩阵：GPT / Claude / Gemini / DeepSeek / Kimi / Qwen / MiniMax（2026-06 当下版本，联网核实）
- 数学能力现状 2-3 页：IMO 金牌线（AlphaProof → 2025 金牌）、AlphaEvolve（4×4 矩阵乘法）、FunSearch、FrontierMath、Erdős 问题库事件、陶哲轩 + Lean
- 仍然不行的（埋第 5 章伏笔）
- 「如果你想研究 AI 本身」1 页（评估/推理/对齐/可解释性，数学人入口）

### 第 2 章 · 概念地图（15′，10 页）
- 总览：Chat → Agent → Harness → Workflow 四层
- 每概念 1 页（一句话定义 + 数学场景迷你例子）：Prompt & Context Engineering / 多模态 / API / **Agent**（密度基准页）/ 工具调用·MCP·Skill / **Harness**（Claude Code、Codex、OpenClaw、Opencode；harness engineering）/ 自动化工作流
- 小结：四级阶梯图（已定稿方向，待美化）

### 第 3 章 · 案例故事线（8′，7 页）
「一篇论文的研究之旅」——Zagier 六步，每步一页，只给问法与模糊预告，不剧透 demo：
① 拆解对合定义 → ② p=13 手算轨道 → ③ 代码验证 p≤10⁶（对合性 + 不动点唯一）→ ④ 风车几何解释配图 → ⑤ 生成带图 LaTeX 笔记 → ⑥ arXiv 监测 agent 追踪推广

### 第 4 章 · Live Demo（12′，1-2 页占位 + 现场切出）
五幕：亮论文（1′）→ 拆定义 + p=13（3′）→ 写代码验证（4′）→ 风车图 / LaTeX 笔记（2′）→ 听众彩蛋（2′）

### 第 5 章 · 边界与规范（6′，4 页）
- 翻车实录：编造引用案例（有出处）、看似严谨实则错的数学推导实例、Erdős"解决"事件的另一面
- 学术规范：Nature/Elsevier/AMS 政策现状；数据安全（网页 vs API）；可复现性
- 信任分级表：什么可放手 / 什么必须自己判断

### 收尾（2′，3 页）
- 行动清单「回去就做的三件事」
- 工具与资源页（供拍照）
- 致谢页（注明本套幻灯片由 Claude 制作，附 making-of 截图缩略）

## 4. 视觉设计规范（方向 B · 纸墨）

- **画布**：1280×720 逻辑分辨率，等比缩放适配屏幕；内边距约 26px(上)/56px(左右)。
- **色板**：纸底 `#f8f4ec`、卡片 `#fffdf8`、淡灰底纹 `#f3efe6`、墨色 `#1c1917`、朱砂红 `#b91c1c`（强调/旁注/章节色）、琥珀 `#d97706`（仅第 5 章边界主题）、灰阶 `#57534e / #78716c / #a8a29e / #d6d3d1`。
- **字体**：标题/正文 Noto Serif SC（400/600/900），标签/表格/芯片 Noto Sans SC，终端/代码 JetBrains Mono；**构建期子集化嵌入**（fonttools pyftsubset，仅含用到的字形），离线放映不变样。
- **页面骨架**：页眉（左：朱砂章节面包屑；中/右：页题与小标）+ 1.5px 分隔线；页脚（进度圆点 + 居中页码 `· n / 40 ·` + 右侧"下一站"预告）。
- **密度基准**：满幅 v3 概念页样张（双栏撑满 + 旁注 + 底部对比条）；章节过渡页允许更松；表格类页面优先图形化（参照阶梯图）。
- **保留的版式语言**：双线书眉、朱砂左旁注、纸面水印公式、终端窗（左朱砂粗边 + mono）、数据小块三联。
- **待办**：阶梯图 v4 再美化一轮（用户已认可方向）。

## 5. Live Demo 方案

- **环境**：主讲人 Windows 笔记本 + Claude Code；工作目录 `talk/demo/`（预置 `zagier.pdf`，干净会话；终端大字号、高对比主题、按投影分辨率彩排）。
- **五幕脚本**：见 §3 第 4 章；每幕的提示词在实施阶段写成《demo 跑稿》并彩排校订。
- **风险预案**：彩排 ≥2 次；全程录屏剪辑为备份视频（mp4）；现场断网→手机热点；API 故障→直接播视频；听众彩蛋不可控→限定为"换素数/同类变体"。
- **录屏**：Windows Game Bar 或 OBS，由主讲人在彩排时录制（Claude 准备跑稿与触发清单）。

## 7. 技术架构

- **幻灯片引擎**：手写 ~100 行 JS（方向键/空格翻页、`F` 全屏、URL hash 定位、1280×720 等比缩放），不依赖外部库；全部资源（字体子集、图片 base64、样式）内联为单文件 `talk/slides/ai-research-talk.html`。
- **数学公式**：构建期用 KaTeX 预渲染为 HTML+内联 CSS（运行时零 JS 依赖）；公式量少（Zagier 集合与对合定义等）。
- **图表**：SVG 手绘（阶梯图、时间轴、pipeline 图）；截图类素材以原图存 `talk/assets/`，**构建时 base64 内联**进单文件。
- **PDF 备份**：无头 Edge `--print-to-pdf` + 打印样式（每页一版）。
- **截图存档**：沿用 `talk/making-of/_capture.py` 管线，里程碑即截即archive。
