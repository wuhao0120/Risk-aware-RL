§ 2 概念地图
给 Agent 装上手脚：工具 · MCP · Skill
AI 智能体与科研工作流
工具调用 · TOOL USE
AI 的手
模型本身只会生成文字；"工具"让它能真的做事：运行代码、搜索文献、读写文件、调用计算软件。
数学场景 · 它调用 SymPy 帮你做符号积分，再调用绘图工具画出函数族
MCP · MODEL CONTEXT PROTOCOL
统一的插座
工具种类太多，于是出现了标准接口协议——常被比作"AI 世界的 USB-C"：数据库、arXiv、Overleaf、课题组服务器，做成 MCP 插件后任何模型都能即插即用。
数学场景 · 接一个 arXiv MCP，它就能边聊边检索最新预印本
SKILL · 技能
肌肉记忆
把一套重复流程沉淀成可复用模块：比如"我读论文的五步法"、"我们组的作图规范"。写一次，以后一句话调用，AI 按你的流程执行。
数学场景 · /读论文 zagier.pdf —— 自动跑完拆定义→验例子→记笔记
工具是手 · MCP 是插座标准 · Skill 是肌肉记忆
