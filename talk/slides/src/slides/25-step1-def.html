§ 3 研究之旅 · 第 ① 步
拆定义：让它把"一句话"展开成一页纸
AI 智能体与科研工作流
你问 "这是 Zagier 1990 那篇一句话证明（zagier.pdf）。把那个对合拆开讲清楚：S 是什么集合？三个分支各在什么条件下用？为什么这是良定义的？"
它先把舞台搭清楚
S = { (x, y, z) ∈ ℤ₊³ : x² + 4yz = p }
— 这是有限集：x² < p，且 yz = (p−x²)/4 只有有限种分解
— p ≡ 1 (mod 4) ⇒ x 必为奇数
— 例：p=13 时 S 只有 3 个元素（下一页全部列出）
旁注 · 它没有跳步：每个"为什么"都给了一行理由，看不懂还可以追问。
再把那个映射切成三支
x < y−z
(x, y, z) ↦ (x+2z, z, y−x−z)
y−z < x < 2y
(x, y, z) ↦ (2y−x, y, x−y+z)
x > 2y
(x, y, z) ↦ (x−2y, x−y+z, y)
良定义的关键（它主动补上的）：边界情形 x = y−z 或 x = 2y 不可能发生——否则 p = (x+z)²−z²+... 可分解，与 p 是素数矛盾；且每支的像都落回 S 中。
