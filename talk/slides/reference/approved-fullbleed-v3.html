§ 2 概念地图 · 小结
一张表看懂四个层级
AI 智能体与科研工作流
层级 它是什么 你给它什么 它还给你什么 数学人的典型用法
Chat 网页对话框里的问答 一段文字（或图 / PDF） 一段回答文字 查定义 · 问思路 · 改段落
Agent 会用工具、会循环的 AI 一个任务目标 做完的事：代码、验证、文件 读论文 + 写代码验证例子
Harness 智能体的"驾驶舱"软件：Claude Code / Codex / Opencode… 你的文件夹 / 论文 / 代码库 长期记忆 · 技能沉淀 · 安全围栏 托管整个 LaTeX / 研究目录
Workflow 定时 / 自动触发的 agent 流水线 一次性的规则设定 周期产出：监测、汇总、日报 每早 8 点 arXiv 新论文速报
怎么选
问一句→ Chat
做一件事→ Agent
管一个项目→ Harness
周期性的事→ Workflow
