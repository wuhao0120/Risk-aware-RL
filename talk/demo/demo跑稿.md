## 第二幕 · 拆定义 + 算 p=13（3′）

```
这是 Zagier 1990 年那篇一句话证明两平方和定理的论文（zagier.pdf）。
请读一遍，把那个对合拆开讲清楚：S 是什么集合，三个分支各在什么条件
下使用，为什么这是良定义的。然后用 p=13 把 S 的所有元素列出来，对合
怎么配对、不动点是谁，算给我看。
```

预期：它读 PDF → 给出 S 定义与三分支逐条解释 → 列出 S(13) 三元素、(1,3,1)↔(3,1,1) 互换、(1,1,3) 不动点。
口播要点：注意它是"看"了 PDF 原文（含公式），不是我转述的。
若它解释啰嗦 → 临场追问：`太长了，三句话讲清楚第二个分支为什么把 (1,1,3) 固定住。`

## 第三幕 · "我不信"——写代码验证（4′）

```
我不完全信。写一个 verify.py：对 p≤10000 全量验证这是 S 上的对合且
不动点唯一；对 p≤1000000 验证不动点公式和两平方和表示。跑给我看结果，
告诉我两段各覆盖了多少个素数、用了多久。
```

预期：写出 ~60 行脚本并自己运行；约数秒出结果（参考答案：609 / 39,175 个素数）。
等待话术（它写代码的 1-2 分钟）：
> "它现在在写枚举 S 的代码——注意它会自己跑、报错自己修。正好我们看看它写的对合函数和论文里的三个分支是不是一回事。"
若现场卡顿超 3 分钟 → 口播"时间关系直接看我彩排时它写的版本"，切 `_stash/verify.py` 跑 `python verify.py` 与 `python verify.py 13`。

口播：从"读不懂"到"一份能存档的笔记"，整个过程 10 分钟，全程可复查。

## 第五幕 · 听众出题（2′，弹性）

> 口播：现在你们出题。换个素数？比如说一个四位数的 4k+1 素数？

```
听众指定 p=____：用 p=____ 把整个故事重演一遍：列 S、配对、找不动点、
给出两平方表示。
```

兜底题库（无人响应时自问）：`p=2026 不是素数也不 ≡1 (mod 4)——那 2027 呢？2029 呢？谁能最快告诉我哪个能写成两平方和？让 AI 现场验证大家的答案。`
变体问题应对：超出 Zagier 范围的（如 p≡3 时为什么不行 / 四平方和）让它口头回答即可，不强求代码——`简要回答，不用写代码。`
